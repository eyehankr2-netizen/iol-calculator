# IOL Calculator 설치 및 사용법

## 1. PC에서 먼저 열어 보기

`app` 폴더 안의 `index.html`을 더블클릭하면 크롬이나 엣지에서 열립니다. 인터넷 연결은 필요 없습니다. 폰 화면처럼 보고 싶으면 키보드 F12를 누르고 왼쪽 위의 휴대폰 모양 아이콘을 누르면 됩니다.

## 2. 폰에서 바로 시험해 보기

빠르게 써 보는 용도입니다.

1. PC 카카오톡의 나와의 채팅으로 `app/index.html` 파일 하나를 보냅니다.
2. 폰 카카오톡에서 그 파일을 받아 저장합니다.
3. 폰의 내 파일 앱에서 Download 폴더를 열고 `index.html`을 누른 뒤 삼성 인터넷이나 크롬으로 엽니다.

이 방식도 계산은 인터넷 없이 완전히 됩니다. 다만 브라우저에 따라 렌즈 목록이 저장되지 않거나 홈 화면 아이콘을 만들 수 없을 수 있습니다. 저장 가능 여부는 앱의 About 화면에 표시됩니다. 그래서 봉사 현장용으로는 아래 3번 방식을 권합니다.

## 3. 출국 전 정식 설치 (권장)

앱은 GitHub Pages에 올라가 있습니다. 설치할 때만 인터넷이 필요하고, 그 뒤로는 비행기 모드에서도 계속 동작합니다. 팀원에게는 아래 주소만 알려 주면 됩니다.

```
https://eyehankr2-netizen.github.io/iol-calculator/
```

1. 폰 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 메뉴에서 앱 설치 또는 홈 화면에 추가를 누릅니다. 삼성 인터넷에서는 메뉴의 페이지 추가에서 홈 화면을 고릅니다.
3. 홈 화면의 IOL Calc 아이콘으로 앱을 한 번 닫았다 다시 엽니다.
4. About 화면에 `Installed copy: works without internet`이 보이는지 확인합니다.
5. 비행기 모드를 켜고 앱을 열어 계산이 되는지 확인합니다.

## 4. 봉사 전 렌즈 목록 준비

1. 아래쪽 Lenses 탭을 엽니다.
2. 처음 들어 있는 Sample IOL은 Edit를 눌러 고치거나 지웁니다.
3. `+ Add IOL model`을 눌러 가져갈 렌즈의 이름과 A 상수를 넣습니다. 제조사가 Hoffer Q pACD나 Holladay 1 SF 값을 따로 주면 그 칸에도 넣습니다. 비워 두면 A 상수에서 계산합니다.
4. 상수는 현장 생체계측 방식에 맞는 값을 씁니다. 초음파 A-scan과 광학 생체계측기의 상수는 서로 다릅니다.
5. Defaults에서 기본 목표 굴절값을 정합니다. 새 환자를 시작할 때마다 이 값으로 돌아갑니다.

## 5. 환자마다 사용 순서

1. `New patient (clear)`를 눌러 이전 환자 값을 지웁니다.
2. OD 또는 OS를 고릅니다.
3. IOL model에서 렌즈를 고릅니다.
4. K1, K2를 넣습니다. 각막곡률계가 mm로 나오면 K unit을 mm로 바꿉니다.
5. 안축장을 넣고 키보드의 완료를 누르면 결과 위치로 자동으로 내려갑니다.
6. 목표 굴절값을 고릅니다.
7. 경고 상자가 있으면 먼저 읽습니다.
8. 큰 숫자는 목표 굴절값에 맞는 IOL 도수입니다. 노란 줄은 그 목표에 가장 가까운 0.5 D 단위 렌즈입니다.
9. 아래 Compare formulas 표에서 네 공식을 비교합니다. 공식 이름을 누르면 그 공식의 렌즈 표로 바뀝니다.

| 경고 색 | 뜻 | 예 |
|---|---|---|
| 빨강 | 이 공식 결과를 믿기 어려움 | 가파른 각막과 긴 안축장에서 SRK/T 한계 도달 |
| 노랑 | 측정값이나 결과를 다시 확인 | 안축장 20 mm 미만 또는 30 mm 초과, 공식 간 차이 1 D 이상 |
| 파랑 | 참고 정보 | 짧은 눈은 Hoffer Q, 긴 눈은 SRK/T가 흔히 선호됨 |

## 6. 앱이 바뀌었을 때

앱을 고치면 버전 번호가 올라갑니다. 현재 버전은 화면 오른쪽 위와 About 화면에 나옵니다.

- 정식 설치 방식이면 새 파일을 같은 주소에 올린 뒤, 폰이 인터넷에 연결된 상태에서 앱을 두 번 열면 새 버전으로 바뀝니다.
- 파일 복사 방식이면 새 `index.html`을 다시 복사합니다.

## 주의사항

- 환자 정보는 저장하지 않습니다. 폰에 남는 것은 렌즈 목록과 설정뿐입니다.
- 앱을 켰을 때 `Self-test failed` 빨간 띠가 보이면 그 기기에서는 쓰지 마십시오.
- 최종 렌즈 선택은 집도의 판단입니다.
